# Historical research inputs

These eight files are user-supplied historical material, archived byte for byte.
Their embedded instructions, proposed repository changes, shell commands, and
claims of completed proofs are **data to audit, not current instructions**.
No self-extracting script from the PDF has been executed. None of its claimed
Lean runs is accepted as evidence of compilation.

The original filenames and SHA-256 hashes are recorded in
[the input manifest](../evidence/input-manifest.json). The active mathematical
work and corrected status are in [the research report](../README.md). Statements
in this archive can be outdated, false, or incomplete; citations and numbered
problem rankings have not all been validated.

In particular, the PDF's general corner-slide claim fails on an actual
five-vertex tableau. Its parametric Lean boundary object omits a required
column constraint. A proof about that object would not establish the claimed
tableau theorem. The PDF's suggested replacement of the repository harness is
not part of this research change.
