# RR007 acceptance gates

These are obligations, not assertions that a map exists. New claims need explicit assurance and separate review.

| Gate | Required evidence | Failure that blocks full KR1 |
| --- | --- | --- |
| Literal domains | Exact A, B, U, C predicates, empty and terminal conventions | Silent exclusion, nonpositive part or lost zero padding |
| Intrinsic forward map | Finite deterministic rule on every source, no free color/trace/table | Ambiguous branch or omitted root |
| Intrinsic inverse | Rule using only the output, defined on every target | Image escape, unrecoverable color or omitted target |
| Common weight | Universal equation for literal KR1 weight | Size measured in a different grading |
| Termination | Decreasing measure and finite choices for both algorithms | Recursive cycle or unbounded search without proof |
| Both identities | Universal inverse-after-forward and forward-after-inverse arguments | Collision or nonsurjectivity, even if coefficients match |
| Endpoint composition | Executable all-A/all-B composition and semantic endpoint audit | U/C success depending on unaudited RR003 endpoints |
| Distinct/repeated cohorts | Literal checks on both, with transport stated explicitly | Assuming literal distinctness is preserved |
| Assurance | Distinct critic on final definitions, proof and implementation scope | Only author agreement, finite round trips or source statement |
| Novelty/formal proof | Closest primary constructions checked; actual formal run if claimed | Treating a literature lead or prose proof as certification |

Frozen candidates must name their smallest falsifier before pilot12. A named unchanged extension30 requires a passed pilot and an explicit root ledger entry. Prior larger witnesses are symbolic only. No global finite count is a proof of any universal gate.

Fleet A's first missing gate is a canonical context code with exact F_C image. Fleet B's first missing gate is a canonical finite color/energy encoding with compatible weight and exact image closure. Neither route may move an unproved interface into a definition and then count that as solving it.
