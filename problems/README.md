# Problems

Problem programs derived from external results, organised for agent fleets.
Each program folder holds one Markdown file per problem, grouped into category
subfolders, plus a `RANKING.md` that orders the problems and the subresults
obtained so far for the next fleet iteration.

| Program | Source result | Entry point |
| --- | --- | --- |
| [eth/](eth/README.md) | OpenAI, "The Exponential Time Hypothesis is False" (openai/math result 378, preprint dated October 25, 2026) | [eth/README.md](eth/README.md), [eth/RANKING.md](eth/RANKING.md) |

Conventions follow [AGENTS.md](../AGENTS.md): every material claim is labelled
**established**, **proved**, **conjecture**, **empirical**, **unverified** or
**refuted**, and novelty stays **NOT VERIFIED** until the closest prior work
has been inspected.
