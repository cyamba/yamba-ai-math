# Continue the exploration program

Use this handoff in an agent environment with access to this checkout:

> Read `AGENTS.md`, `SKILLS.md`, and `explore/AGENTS.md`. Continue the explore phase of Yamba AI Math Lab: identify mathematically substantial routes to smaller, more capable and reliable AI. Start by surveying the 16 seed briefs rather than assuming the first idea is the best. Compare scientific promise, closeness to prior work, tractability, and the cost of a decisive falsifier. Select one primary angle and at most two supporting angles. Use current primary sources, retain speculative alternatives, and record negative results.
>
> Choose or adapt a bounded program from `programs/`, then assemble the smallest useful fleet. Use the planner and agent cards, assign a separate critic, and preserve provenance and disagreements. A plan or manual packet is not completed research. If real model execution is unavailable, perform the investigation using the host's tools and subagents, or report the precise execution gap; do not substitute synthetic outputs for research.
>
> Deliver an updated research brief, a nearest-prior-work table, one precisely quantified theorem attempt, an independent counterexample search, and the smallest preregistered experiment capable of disproving the proposal. Disclose which sources and proof steps were actually checked. Explain total resource costs and the restrictions behind any claimed advantage over larger models. Promote the idea beyond seed only when the evidence gate in `docs/research-protocol.md` is satisfied.
>
> Keep improvements to the harness itself under `meta/`. Compare changes against a fixed baseline with isolated held-out tasks. Do not let candidate agents redefine their own success criteria or authorize promotion. The immediate objective is useful research evidence, followed by mathematics, architectures, software, and agent systems where that evidence justifies further work.
