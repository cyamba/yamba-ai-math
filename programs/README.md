# Investigation programs

A program turns research briefs into one bounded assignment. The JSON files are examples ready for planning; none has been executed as part of the initial repository.

| Program | Purpose | Fleet |
| --- | --- | --- |
| `evidence-preserving-attention.json` | Relate attention compression to retrieval correctness and rare-fact costs | `explore` |
| `decision-sufficient-world-models.json` | Examine identifiability and decision sufficiency beyond prediction alone | `world-model` |
| `agent-topology-and-correlation.json` | Formulate resource-matched comparisons of team topologies | `topology` |
| `harness-improvement.json` | Design a controlled evaluation of one harness change | `meta` |
| [partition-positivity.json](partition-positivity.json) | Record the initial partition-construction audit and scoped repair | `theorem` |
| [partition-gap-closure.json](partition-gap-closure.json) | Prove finite weighted cancellation and audit the claimed general certificate | `pair` |
| [partition-h3-unimodality.json](partition-h3-unimodality.json) | Investigate a conjectural height-three coefficient family's first differences with complete signed spaces | `pair` |
| [partition-h3-forest-surgery.json](partition-h3-forest-surgery.json) | Test reversible forest split/join rules for the same conjectural coefficient family | `pair` |
| [partition-h3-forest-transport.json](partition-h3-forest-transport.json) | Test sibling-fork transport and preserve an exact Hall obstruction across forest blocks | `pair` |
| [partition-h3-forest-exchange.json](partition-h3-forest-exchange.json) | Test recoverable vertex exchanges, a degree-zero pivot and the necessary capacity of ordered composition sectors | `pair` |
| [rogers-ramanujan-bijections.json](rogers-ramanujan-bijections.json) | Audit the actual bijection gap and plan one precise Rogers–Ramanujan-type target | `pair` |
| [rogers-ramanujan-discovery.json](rogers-ramanujan-discovery.json) | RR003: bounded discovery toward a complete KR1 bijection; restricted results and universal gaps preserved | `pair` |
| [rogers-ramanujan-construction.json](rogers-ramanujan-construction.json) | Bounded KR1 weighted-to-cluster construction attempt, preserving exact failures and the unresolved bridge | `pair` |

Read `contract.md` before creating or executing a program. A planning or packet-generation command prepares work; it does not establish that the research was performed. Runtime-generated reports must identify the execution mode and preserve any missing evidence.
