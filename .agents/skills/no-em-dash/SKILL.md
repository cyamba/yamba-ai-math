# Publication punctuation rule

Do not use the Unicode em dash (U+2014) or doubled hyphens as sentence punctuation in authored material. Use commas, colons, semicolons, parentheses or periods. Cover titles, website metadata, alt text, LaTeX prose, social copy and academic articles. Preserve necessary programming, CLI, YAML and mathematical syntax. Check all new public prose before merging. Apply to Codex, Claude Code and other authors. This rule never weakens the separate mathematical review standard.
