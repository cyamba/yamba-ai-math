# Quality checklist

Run this before anything leaves the understanding layer.

## Truth

- [ ] The status and source of every explained claim appear at the top, with inspection level or
      proof assurance.
- [ ] Nothing was upgraded: no "proved" for a checked range, no "known" for a lead.
- [ ] Statements are complete: domains, quantifiers, hypotheses, edge cases.
- [ ] Every simplification says what it omits; none is false at its own level.
- [ ] Gaps, errors and new ideas found along the way are recorded and routed, not patched.

## Evidence

- [ ] Every number, table and example comes from saved code or a written-out hand check.
- [ ] The checked range is stated; "none found up to N" is never written as "always".
- [ ] Figures are generated from the same definitions as the examples, with the command recorded.
- [ ] Bijections shown are checked to be mutually inverse on the displayed cases.

## Understanding

- [ ] The key idea is stated in one sentence.
- [ ] Each hypothesis has a non-example showing why it is needed.
- [ ] Each analogy states where it breaks.
- [ ] The level matches the audience; jargon is defined before use.
- [ ] There is at least one check question or exercise for teaching material.

## Presentation

- [ ] Each figure has one message, a caption saying what to notice, alt text with the takeaway,
      and a colorblind-safe encoding that does not rely on color alone.
- [ ] Primary sources are cited next to claims; sources a research file relies on are in the
      reading list.
- [ ] No em dashes or doubled hyphens in prose, titles, captions or alt text.
- [ ] No third-party text reproduced beyond short quotations.
- [ ] Nothing is published or submitted without the operator's authorization.
