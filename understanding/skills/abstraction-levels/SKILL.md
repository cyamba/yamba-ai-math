# Explain at several levels

Use the ladder, audience profiles and paths in [levels.md](../../references/levels.md).

## Steps

1. **Audience and goal.** Pick a profile, an entry level and a target level, and decide whether
   to show the whole ladder or one path through it.
2. **Two axes, not one.** Abstraction (concrete objects to general structures) and rigor
   (heuristic to formal) vary independently. A concrete, fully rigorous computation and an
   abstract heuristic are both legitimate stops.
3. **True at every resolution.** A simpler level drops detail but never asserts something false.
   Mark omissions ("we ignore the case n = 0 here").
4. **One running example** across all levels anchors the reader as the abstraction rises.
5. **Link the levels.** Each level ends with the question the next level answers.
6. **Mixed audiences**: write the body at the middle level and put deeper levels in boxed or
   collapsible sections, simpler ones in a "picture first" opening.
7. **Teaching material**: add one "check yourself" question per level.

## Output

A level map (which levels, in which order, for whom), then the levels, each headed by its name
and a one-line purpose.
