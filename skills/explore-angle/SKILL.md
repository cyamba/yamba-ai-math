# Explore a research angle

Start from the user’s intended mechanism or task. Prefer one precise separation over a universal claim that smaller networks outperform larger ones. Specify a task family, data distribution, model classes, learning procedure, error metric, and total resource boundary. A larger unrestricted class may contain the proposed smaller model.

Check primary literature for the proposed mechanism, the closest equivalent construction, and a negative result. Record verified source links and the date checked. If source access is unavailable, distinguish remembered leads from checked evidence. Do not infer novelty from a short search.

For geometry, state the transformation that preserves the task and how outputs should transform. For attention, separate logits, candidate selection, normalized weights, value operators, and decoding. For hallucinations, distinguish source-relative support, factual correctness, and selective risk at a stated coverage.

Return at most three ranked angles. Each needs the question, mathematical objects, closest known result, candidate new theorem, weakest useful assumptions, a failure example, an experiment, and expected resources. Label contributions as `established`, `proved`, `conjecture`, `empirical`, `unverified`, or `refuted`; state definitions separately, disclose proof assurance, and keep a proof sketch as an obligation.

End with one bounded next step and a stop condition. The [explore fleet](../../fleets/registry.json) can distribute this work when delegation is available; it is optional, and the skill does not authorize external publication or paid runs.
